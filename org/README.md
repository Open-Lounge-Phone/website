# GitHub organization files

`dot-github/` is the source of the **[Open-Lounge-Phone/.github](https://github.com/Open-Lounge-Phone/.github)**
repository, which is the published copy: `profile/README.md` is the organization page at
https://github.com/Open-Lounge-Phone and `FUNDING.yml` is the default Sponsor button for the
organization's repositories. Edit here, then copy the folder's contents into that repository.
